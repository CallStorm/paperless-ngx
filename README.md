# 计划

**基于`paperless-ngx`开发一个融合AI的高效文档管理系统。**




## `paperless-ngx`介绍

Paperless-ngx 是一个由社区支持的开源文档管理系统，可将您的纸质文档转化为可搜索的在线档案，从而帮助您真正实现“少用纸张”。 当然，在实际使用中，
不简简单单是少用纸张，有强大的文件处理和检索功能，可以帮我我们大大的提高内容管理效率。

**主要特性有:**

1. **智能文档组织与索引**：支持通过标签、通信方、文档类型手动分类，同时借助机器学习自动为文档分配这些属性，提升整理效率。
2. **本地存储与隐私安全**：数据仅保存在用户本地服务器，不传输、不共享，保障文档隐私与数据安全。
3. **多语言OCR与搜索能力**：基于Tesseract引擎实现100+语言OCR识别，将图像类文档转为可搜索文本；全文搜索支持自动补全、结果高亮与相似文档推荐。
4. **长期存储与多格式兼容**：以PDF/A格式（适合长期存储）保存文档并保留原件，兼容PDF、图像、Office文档、纯文本等多种格式。
5. **现代化网页交互体验**：提供可自定义仪表盘、拖放上传、批量编辑、自定义视图与字段，支持公共链接分享（可设过期时间），操作便捷直观。
6. **精细权限管理**：内置多用户权限系统，既支持全局权限配置，也可针对单个文档/对象设置访问权限，控制精准。
7. **灵活的邮件与工作流管理**：可配置多邮箱账户及规则导入文档，支持自定义工作流（设置触发条件与对应操作），掌控文档处理全流程。
8. **高效处理与健康检查**：针对多核系统优化，支持并行处理多文档；集成完整性检查器，确保文档存档无损坏。
9. **多场景显示与编辑**：提供文档列表多样式浏览、深色模式，支持侧边栏精简视图；支持文档并排编辑、自定义字段修改及下载、删除等操作。
10. **邮件规则精准配置**：可按附件类型、文件名匹配筛选邮件，设置处理后动作（如删除邮件），并自动分配文档标题、标签等属性。
11. **跨设备兼容**：适配移动设备，支持随时随地通过移动端访问与管理文档。
12. **活跃社区与扩展支持**：提供GitHub、Matrix社区支持，支持多语言翻译（Crowdin平台），兼容多种扫描仪/软件，Office文档处理可通过Apache Tika扩展启用。
